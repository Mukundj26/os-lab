Save and exit.
Step 3: Create Dockerfile
nano Dockerfile


Paste:

FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY app.py .

EXPOSE 5000

CMD ["python", "app.py"]



Save and exit.
3. Install and check Docker
First check whether Docker is available in Ubuntu WSL:
docker --version
docker info


If Docker is not installed or the Docker daemon is not running, you need a Docker engine. One convenient option is Docker Desktop with Ubuntu WSL integration enabled. You can then execute Docker commands directly from Ubuntu.

Official guide: Docker Desktop WSL integration.
4. Build the Docker image
Make sure you are inside the AI_ML_Docker directory.

Execute:
docker build -t aiml-house-price .


Explanation:
- docker build creates an image.
- -t assigns a name to the image.
- aiml-house-price is the image name.
- . means use the current directory.
Check the created image:
docker images


5. Run the Docker container
Execute:
docker run -d -p 5000:5000 --name aiml-container aiml-house-price


Explanation:
Command	Meaning
docker run	Runs a container
-d	Runs in background
-p 5000:5000	Maps host port to container port
--name	Assigns container name
aiml-house-price	Docker image name

Check the container:
docker ps
